# HeartOps homepage: historical sample

A historical volunteer-coordination homepage prototype with a local shift-recovery preview, separate approvals, and simulated acceptance.

This is an earlier design experiment, preserved separately from the current RevenueRescue guest workspace. All names, stories, records, and results are illustrative. It does not send messages, process donations or payments, authenticate users, call AI services, or connect to AWS.

Open `index.html` in a browser. Readable markup, styles, interactions, and local assets are stored separately in `index.html`, `styles.css`, `app.js`, and `assets/`.

Photo and font provenance is recorded in `ASSETS.md` and `FONT-SOURCE.md`. Stock photos do not establish an affiliation or endorsement. No generated combined HTML, screenshots, private project documents, or real customer data are included in this historical source copy.

The active guest application is `apps/revenuerescue/` at the repository root. Its generated integrated file is separate under `integrated/`.

The historical state checks can be run from this folder with `node --test app.test.cjs`.
