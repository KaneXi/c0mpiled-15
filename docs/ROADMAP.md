# Relay delivery scope

The immediate release is one complete, persistent volunteer coordination workflow:

1. A manager reviews or creates a draft shift and publishes it.
2. The server automatically schedules check-ins, respecting permission, quiet hours and pause state.
3. A clearly labeled call simulator supplies the volunteer's whole conversation. Configured Amazon Bedrock interprets it.
4. A coverage gap creates a short candidate plan. The manager chooses Yes, No or Assign myself.
5. Approved outreach proceeds sequentially, revalidates eligibility, records every call and stops once coverage is restored.

The user requested fast delivery and waived the model-review workflow. Marketing pages, analytics charts, animations and advanced settings are excluded from this release.

Remaining full-spec integrations: verified live Connect transport and contact authorization; production manager identity and organization membership; official AWS App Monetization test checkout/entitlements/metering; AWS Cost Anomaly Detection notifications to an owner-selected destination. These are not claimed as working by the guest demonstration.
