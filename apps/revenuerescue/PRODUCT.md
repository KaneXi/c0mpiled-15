# RevenueRescue guest demo

Surface mode: Operate. An English-only, client-local example for nontechnical staff at fictional Juniper Studio, a small salon.

The guest can add fictional inquiries, review and edit a sample follow-up, approve it, simulate sending, arrange or reschedule an appointment, and record an outcome. The original appointment remains confirmed until its replacement passes availability checks. A request is not an available slot; a booking is not a sale; staff-reported sale value is not a verified payment.

Four primary screens: Today, Customers, Appointments, Results. The guided tour is optional and replayable. Voice examples are illustrative text, with no microphone or telephone access. All workspace data lives in React memory and resets on refresh. No account, API, AWS, external messages, live billing, or production service is part of this delivery.
